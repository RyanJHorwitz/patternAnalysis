# Folder Contents

1. Single_Functions: Contains scripts for mean center, median center, weighted mean center, and constrained weighted mean center. Input is a single Spatstat ppp object.

2. Batch_Functions: Contains scripts for mean center, median center, weighted mean center, and constrained weighted mean center. Also includes a comparison function that suggests the best measure of central tendency for a pattern dataset based on prediction distance to true. Input is a list of Spatstat ppp objects.
